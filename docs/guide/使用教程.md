# Rewind 使用教程(v0.1 初稿)

> 发布前补截图;命令与行为均与当前引擎实测一致。

## 一、它是什么

Rewind 把高清视频/图片**做旧**成有年代感的低画质:VHS 录像带、翻录 DVD、CRT 大屁股、老胶片、监控、彩屏手机。全部在你本机完成,没有服务器,断网可用,不需要显卡。

## 二、安装(发布后)

- Windows:双击安装包,一路下一步;Linux:AppImage/ deb;macOS: dmg(首次打开按提示右键→打开)
- 首次启动无需下载任何模型——**装完即用**

开发/尝鲜构建:见 README「构建」节(引擎自带 CLI 可脱离界面直接使用)。

## 三、三步出片

1. **拖入素材**(视频 mp4/mov/mkv…,或图片 png/jpg,支持批量)
2. **选年代**:
   - 拖**年代轴**(1965→2026)到目标年份,或
   - 从预设列表选一个成品风格
3. 点**开始做旧** → 输出默认落在素材旁 `Rewind输出/` 文件夹,文件名自动带预设标记(如 `片名_era_1988.mp4`);用本地 Web 版时,每行完成后还有「保存」链接直接把成品下载到浏览器下载目录

## 五、四个玩法

- **做旧系数(几手)**:强度管"这一手有多重",系数管"几手"。拖到 3 手就是"下载→重采样→再压缩→上传"往返三次,一次算好不用重复点;6 手起进爆炸档。**上限 8**——实测同尺寸同 q 反复转码会收敛,再高只是白等。导出尺寸不随它变。
- **偏色 · 变绿(默认关)**:包浆 ≠ 发绿。想要"贴吧/QQ 那一路"的糊到发绿,把这根拉起来(0–100%),它随手数逐代加深;不开就一路保持中性灰雾。CLI:`--override preset.cast=0.6`。
- **年代轴**:参数不是开关而是渐变——1988 和 1994 的磁带味道不同,拖过去对比。它是"派生预设",不会混进上面的预设列表;想留住就点「存为我的预设」。
- **「再翻录一次」**:对上个成品再走一轮真编码——这是**物理复手**,和做旧系数的区别在于它复现的是"在已经压过的素材上继续压"(蚊噪与块错位更真实),但要多等一趟全片。
- **🎲 换一批**:划痕/雪花/抖动由随机种子驱动;不满意构图?换一批重新抽,种子会记录在预设里可复现。

## 五·五、把"像"拧紧的两个旋钮:画幅与帧率

年代轴决定"用什么预设",这两项决定"比例对不对"——老片之所以像老片,一多半在这两条上:

- **画幅与制式**:1965–2005 的电视是 4:3,而且存的是**非方形像素**(NTSC 10:11、PAL 12:11、DV 59:54)。选 `4:3 + 裁切` 就是真电视当年的取景(居中裁掉两侧);选 `黑边` 保全画面但两侧留柱;选 `压扁` 得到的是"翻录失败"的味道;选 `只降不升` 是平台式缩放(小图不会被放大)。`电视切边` 是显式过扫描(真CRT 会切掉每边 3–7%)。`量化范围` 选 `pc` 得到监控/VCD 那种发灰的黑场。
- **帧率与节奏**:老素材的低帧率是**丢帧**而不是补帧,所以默认 `纯丢帧(round=down)`;想更"卡"可切 `就近补帧`。`快门模糊` 是关键开关——帧率低到 12fps 以下,若运动模糊不随帧距放大,观感就是"游戏掉帧"而不是"老摄影机"。`3:2 节奏` 给胶片转磁带的招牌抖动。
- 两项都在界面上有控件,也都能写成 CLI 覆盖:`--override fps.fps=12.5 --override resize.dar=4:3 --override resize.fit=crop`。覆盖只作用于这一次任务,**不改预设文件**,年代轴拖动画也不会冲掉你钉住的参数。做旧系数同理:`--override preset.aging=6`。
- 想调更细的:展开**专家参数**面板(全部 stage 逐项,带区间;默认收起),或直接改 JSON(见「预设格式」)。
- **成品存成 JPG 更像**:图片输入默认输出同格式(PNG 无损,包浆味会被自己抹掉)。

## 六、参数与自定义

- 界面右栏的**高级参数**是引擎清单(`rewind-core describe`)驱动渲染的,75 个 stage 参数按 12 个分组手风琴展开;每个参数三态:`跟随预设`(显示推算值)→ `跟随源`(上传后取 probe 值)→ `钉住 ●`。**只有钉住的项会作为 `--override stage.key=value` 发给引擎,预设文件永不改**,「清除全部自定义」一键回到跟随态。
- **VHS 那一档有 12 个信号级旋钮**(带速 / 色度损失 / 磁带锐化 / 边缘波纹 / 跟踪噪声带高与扭曲 / 磁头切换带高与错位 / 雪花 / 亮度拖尾 / 色度水平与垂直滞后)。它们的**默认值等于引擎今天生效的值**,所以只动其中一个才只改那一处;`带速 = 0` 是"根本不用磁带模型"(整块关掉),不是把某个参数设成 NONE。想关掉某条噪声带就把它的高度写成 `0` 行。
- **界面滑杆的上限是"看得见又不至于糊掉"的档位,不是引擎能吃的极限**:CLI 可以再往外推(如 `--override ntsc_vhs.snow=20` 是纯噪点),清单里两份区间都写明了(`min`/`max` 与 `hard_min`/`hard_max`)。
- 改画幅的默认动作是**裁切**,不是压扁:16:9 素材进 4:3 交付画幅会左右各裁掉一块;要"整幅塞进去"的老味道,在高级参数里把「画幅适配」选成 `stretch`。
- 预设文件是 JSON(schema v1),在用户预设目录可改可存:`preset-save` 或 CLI 生成
- CLI 直用(脚本党友好):
  ```
  rewind-core run --preset presets/dvd2005.json --input in.mp4 --out-dir out/
  rewind-core era 1988 --write my.json      # 生成某年代联动预设
  rewind-core reclip --input out/x.mp4 --times 2
  rewind-core reroll my.json                # 种子+1
  ```

## 七、常见问题

**Q:输出为什么"糊"了?** A:这就是目的(见首页)。**Q:要多久?** A:10 秒 1080p 素材 8.5~33 秒,取决于风格;批量 20 文件约半分钟。**Q:文件会被上传吗?** A:不会上传到任何远端。桌面版整个应用零网络请求;本地 Web 版(`rewind-core serve`)也是在你自己机器上起的进程,素材只经 127.0.0.1 回环交给本机引擎,不出这台机器。**Q:输出文件里有什么标记?** A:默认嵌入"经 Rewind 做旧处理"元数据(反伪造条款,见协议)。**Q:声音也会变旧吗?** A:会——每个预设带配套音频预设(带限/底噪/bitcrush 等)。

## 八、已知边界(v0.1)

- 输出画布默认保持源分辨率(监控/VHS 风格保留原生低分辨率画布)
- HDR 源会先转 SDR 再做旧;变帧率源自动转固定帧率
- 4K 超长视频建议先分段;当前为 CPU 管线
