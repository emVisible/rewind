# Rewind 预设格式(schema v1)

> 预设 = 有序的做旧 stage 列表,JSON 描述,引擎按 stage 名自动选路(ffmpeg / 像素管道)。
> 内置目录 `presets/`;用户目录(优先级更高,同名覆盖):
> Windows `%APPDATA%\Rewind\presets`,Linux/macOS `~/.local/share/Rewind/presets`。

## 顶层结构

```json
{
  "id": "vhs1990_ntscrs",        // 唯一标识,也是文件名
  "name": "VHS 家用录像带(信号级)",
  "era": 1990,                    // 年代轴定位(1965-2026;0=不属于年代轴)
  "schema": 1,                    // 高于引擎支持版本会拒绝加载(迁移钩子)
  "note": "可选说明",
  "video": [ { "stage": "...", "params": { ... } } ],
  "audio": [ ... ],
  "calibrated": "定标记录(人读)"
}
```

## 视频 stage

| stage | params | 路线 | 说明 |
|---|---|---|---|
| `resize` | `w,h,flags` 或 `mode:"source_canvas",flags`;新增 `dar`("4:3"/"15:11"/"16:9")、`fit`("crop"默认/"pad"/"stretch")、`par`("10:11"/"12:11"/"59:54"/"1:1")、`overscan`(0.85-1.0)、`range`("tv"默认/"pc") | ffmpeg | 执行顺序固定:过扫描裁切 → 按 `dar` 居中裁 → `scale`(带 `range`)→ 黑边 → `setsar/setdar`。改了 `par` 会先做去挤压,否则交付画面上人会被拉扁。`source_canvas`=拉回源画布 |
| `fps` | `fps` + `round`("down"默认=纯丢帧/"near"=就近补帧)、`shutter`(0-1 快门模糊)、`cadence`(null/"telecine32") | ffmpeg+像素段 | 低帧率要"旧"不要"卡"靠 `shutter`:模糊随帧距放大。像素段同样生效 |
| `noise` | `alls, allf`("t"/"u"/"t+u") | ffmpeg | 时域/频域噪声 |
| `color` | `saturation,contrast,brightness,green_mid,blue_mid` | ffmpeg | eq + colorbalance |
| `color_fade` | `strength` 0-1 | ffmpeg | 胶片褪色(抬黑/降饱和/偏暖) |
| `band_quantize` | `level`(8–48)`chroma`(bool) | ffmpeg | 色阶断层。本机 ffmpeg 4.4.2 没有 posterize/banddither,所以用 `lutyuv` 手搓;默认只砍亮度,`chroma:true` 才连色度一起砍 |
| `unsharp` | `amount`(0–3,默认 0)`size`(3–13 的奇数)`chroma_amount`(0–3) | ffmpeg | 锐化/振铃。`amount=0` 时**整条滤镜都不插**(不白跑一趟);做旧系数 ≥6 手会自动带出振铃 |
| `asymmetric_lowpass` | `luma_radius,chroma_radius` | ffmpeg | 亮度/色度非对称低通(VHS 色度渗漏) |
| `interlace_comb` | `mode:"merge",refps` | ffmpeg | 隔行梳齿近似(引擎自动处理翻倍高度) |
| `chroma_decimate` | `to`("411"/"420"/"422") | ffmpeg | S1 色度抽稀往返:色度带宽低于亮度是消费级磁带/监控的物理特征 |
| `matrix_roundtrip` | `{}` | ffmpeg | S1 BT.709↔BT.601 矩阵往返(复合解码色偏) |
| `overlay_timestamp` | `format,rec_badge` | ffmpeg | 时间戳/REC;格式用 `%T` 不用字面冒号 |
| `codec_roundtrip` | `codec,q` 或 `codec,bitrate`(+`container,audio_bitrate,video_only`) | ffmpeg 多趟 | **真编码器伪影**;H.263 只吃 176x144/352x288 等固定尺寸 |
| `tape_ends` | `head,tail,intensity`(秒/秒/噪声量) | ffmpeg | 磁带头尾穿带雪花(用 filter timeline `enable` 实现) |
| `ntsc_vhs` | `seed` + 12 个信号级旋钮(见下) | **像素** | ntsc-rs 官方信号级模拟(梳齿/串扰/磁头切换)。**全部可缺省**:不写 = 用上游默认值,成品与接入旋钮之前逐字节相同 |
| `crt_display` | `scanline,barrel,aberration,persistence` | **像素** | 自研 CRT:扫描线/桶形/色散/荧光粉拖影 |
| `film_damage` | `seed,scratches,dust,flicker` | **像素** | 自研胶片损伤,种子驱动 |

### `ntsc_vhs` 的 12 个信号级旋钮

写预设时**只写你想改的那几个**就够了:其余全部缺省 = 上游默认值,画面与"还没接旋钮"时逐字节相同。
下面这张表的权威出处是 `rewind-core describe`(界面按它渲染控件,这张表只是给人看的抄本,漂了以清单为准)。

| 参数 | 滑杆区间 | 默认 | 意义 |
|---|---|---|---|
| `vhs_tape_speed` | 0–3 | 2 | 带速:`0` = 根本不用磁带模型(**整个 VHS 块关掉**,不是留着一堆别的 VHS 处理)、1=SP、2=LP、3=EP |
| `vhs_chroma_loss` | 0–0.05(CLI 可到 0.2) | 0.000025 | 色度相对亮度丢多少 |
| `vhs_sharpen` | 0–5 | 0.25 | 磁带锐化(倍) |
| `vhs_edge_wave` | 0–20 | 0.5 | 边缘波动(像素) |
| `tracking_noise_height` | 0–120 | 12 | 跟踪噪声带高度(行);`0` = 不画这条带 |
| `tracking_noise_wave_intensity` | −50–50 | 15 | 这条带的扭曲幅度 |
| `head_switching_height` | 0–24 | 8 | 底部磁头切换带高度(行) |
| `head_switching_horizontal_shift` | −100–100 | 72 | 切换带的横向错位(像素) |
| `snow` | 0–0.5(CLI 可到 100) | 0.00025 | 雪花/白点强度(线性;实测 0.05 满屏、0.5 已经很重、100 是纯噪点) |
| `luma_smear` | 0–1 | 0.5 | 亮度拖尾 |
| `chroma_delay_horizontal` | −40–40 | 0 | 色度水平滞后(像素) |
| `chroma_delay_vertical` | −20–20 | 0 | 色度垂直滞后(行) |

四条要记住的:

- **默认值不是 0**。上游 `SettingsBlock` 的默认是 `enabled: true`,12 行 / 8 行 / 72 像素 / 0.25 倍 / 0.5 像素这些内层值才是"画面今天的样子"。照抄"0 = 关"会让"往管线里插入一段 `ntsc_vhs`"这件事悄悄改掉成品。
- **想关掉某一块就把它的尺寸类参数写成 0**(0 行 = 没有可见带),不是去禁整个块。
- **滑杆区间 ≠ CLI 可用区间**:前者是"看得见又不至于糊掉"的档位,后者是管线还能照办的范围。`--override ntsc_vhs.snow=20` 是能用的(带码拒绝的是越硬上限),界面上则拉不到 —— 这是刻意的两级。
- 这几个名字同样用于 `--override ntsc_vhs.<key>=<值>`;拼错或越界会当场带码报错并列出可用名。

## 音频 stage

| stage | params | 效果 |
|---|---|---|
| `bandlimit` | `highpass,lowpass` | 带限(电话 300-3400、磁带 120-8000) |
| `gain` | `volume` | 电平 |
| `bitrate_roundtrip` | `bitrate`("64k") | 编码码率劣化 |
| `resample_roundtrip` | `rate`(8000) | 采样率往返 |
| `bitcrush` | `bits,mode,aa` | 位深破碎(acrusher) |
| `tape_hiss` | `color,amplitude,mix_weight` | 底噪(brown=胶片放映机,pink=磁带) |
| `mono` | `{}`(必须带空 params) | 单声道下混 |
| `wow_flutter` | `freq,depth` | 磁带抖晃(vibrato+tremolo 双 LFO) |

## 语义规则

- **像素 stage 之间可以插入 ffmpeg stage**(自动切多段像素管线);段序即处理序
- **强度乘子**(`--intensity 0.2–2.0`)只缩放幅度类参数(noise/半径/fade/damage/CRT/q 与码率反向),带钳位;不改结构类 stage(隔行/时间戳/codec 种类)
- **种子**:`ntsc_vhs.seed`、`film_damage.seed` 驱动可复现随机;`reroll` 命令全体 +1(写用户目录同名覆盖)
- **迁移**:`schema` 大于引擎支持即报错;未来版本升级在加载钩子里做字段迁移

## 常用命令

```bash
rewind-core era 1988 --write my.json          # 生成年代轴预设
rewind-core preset-save --dir D --name n --from my.json
rewind-core reroll my.json --write my.json    # 换一批
rewind-core run --preset my.json --input in.mp4 --out-dir out/ --intensity 1.4
rewind-core describe                          # 参数清单(JSON):控件、区间、单位、默认值
```

## 参数覆盖(不改文件也能调)

预设 JSON 是"预设",覆盖是"这一次我要钉住什么"。二者分开存,所以年代轴重生成、换一批、切预设都不会冲掉你的临时决定。

```bash
rewind-core run --preset presets/cctv2000.json --input in.mp4 --out-dir out/ \
  --override fps.fps=12.5 --override resize.dar=4:3 --override resize.range=pc
```

- 写法 `stage.key=value`,值按字面量解析(`true/false`、整数、浮点、其余当字符串);可重复。
- 参数名会先对着 `describe` 清单校验:拼错当场报错并列出该 stage 的可用参数(**不静默**——serde 本来会把未知字段悄悄丢掉)。
- 预设里没有这个 stage 时,引擎按管线位次(`rank`)插入一个并补上清单默认值:`fps` 排在 `noise` 之前,不会因为"后加"而改语义。
- 应用顺序:载入预设 → 套覆盖 → 乘全局强度(强度只缩放幅度类参数,见上表 `scaled_by_intensity`)。
- 界面的一级控件与专家面板就是这套覆盖的图形化入口,持久化在设置的 `overrides` 字段里。
