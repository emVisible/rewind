**执行中修正的三条设计(原方案不够真)**:
1. 瓦片必须按**成品画布 1:1 中心取块**。首版把 720×480 缩到 480×270,扫描线与宏块被平均掉了,对比图等于没做;小画布(3GP 176×144)用 `neighbor` 整数放大保真像素块。
2. 静帧对比图**天然低估时间型预设**(VHS 跟踪带、隔行梳齿、代际块噪都在运动里)。动图 hover 预览(每预设 0.8s 循环 webm)列入 M5b,不是可选项。

**顺带补的安全洞**:`/file` 原本能读任意绝对路径,且响应带 `Access-Control-Allow-Origin: *` —— 本机任意网页都能借 127.0.0.1 服务读磁盘。现在:去掉 CORS 头 + `/file` 只放行本服务登记过的路径(上传件、成品、预览帧),未登记一律 403(实测 `README.md` → 403)。

## 2. 单件流程与状态机

```
[空] 拖入/选择文件 ──probe──> [预览] 改参数(800ms 防抖) ──> 预览自动重渲
      │                            │
      │                            └──> [开始做旧] ──> [处理中] ──> [完成卡]
      │                                                     │         │
      └── 多文件:进"待处理条带",点击切换焦点件;焦点件走完上面流程    └──> 回[预览](参数保持)
```

- 处理一次**永远只有一件**在跑(引擎本就单件顺序执行,界面把它显性化)。
- 多选/拖多文件:全部进待处理条带(底部 96px 缩略图行,带状态点),处理权交给用户逐件点,或开"连续做完"(M5 后的队列抽屉)。
- 完成卡常驻(非模态):缩略图 + 文件名 + 大小/时长 + [打开所在目录](主)/[再来一次](参数保留,文件名自动 -1)/[换一个](回 hero)。
- 状态转移可撤销:处理中取消 → 回预览态且参数不丢;预览态换预设 → 参数覆盖保留(覆盖就是钉住)。

## 3. 三态默认值继承(钉住 > 预设 > 源)

上传完成后对当前焦点件跑一次 `rewind-core probe`(引擎已有),得到 `{宽,高,fps,时长,编码,容器,大小,VFR?,HDR?}`。三类来源的定义与呈现:

| 状态 | 呈现 | 语义 |
|---|---|---|
| 跟随预设(默认) | 控件显示推算值,浅灰:`跟随预设(720×480 @15fps)`,tooltip 说明预设名 | 不改预设文件,本次任务按预设走 |
| 跟随源 | 标签变 `跟随源(29.97fps)`,值取自 probe(画幅/fps/尺寸) | 以源内容为基准(用户原话的实现) |
| 钉住 | 控件出现修改点(●),值生效;双击控件复位到跟随预设;shift+双击 = 跟随源 | 生成 `--override` |

- 适合"跟随源"的参数:**画幅(dar)、帧率(fps)、存储尺寸(w/h)、量化范围**。其余参数默认跟随预设(噪声/损伤/编码等本就该按预设)。
- 上传一个新素材**不清空**已有钉住(用户是"换一种料同调味"的常见操作);只刷新跟随类的推算值与"跟随源"的取值。清空靠显式"清除覆盖"。
- 引擎侧新增:`probe` 返回补充 `dar`(由 SAR 推算)、`vfr`(avg≠r_frame_rate)、`codec/container/size`(ffprobe format+stream 联合),serve 的 `app_info` 不变;UI 在文件落库时调用。

## 4. 帧率分档滑块

- 档位表(索引式,不按数值线性):`[跟随, 60, 50, 30, 29.97, 25, 24, 23.976, 18, 16, 15, 12.5, 10, 7.5, 6.25, 5]`。
- UI:`<input type=range min=0 max=15 step=1>` + 刻度线 + 当前值读数(`29.97 fps` 精确到小数);键盘 ←/→ 按档步进,Home/End 到两端。位置 0 显示"跟随"(跟随预设,样式与 §3 一致)。
- manifest 侧:`fps.fps` 的 kind 从 `float` 改为 **`stepped`**,附加 `stops` 数组;渲染器按 kind 特判(一个参数一个控件的铁律不变)。
- 后端不动(仍收数值覆盖)。

## 6. 预览策略(守住"预览即成品")

- 自动重渲:参数/预设/强度任一变化后 800ms 防抖触发 `preview_compare`(真管线,1.2s 窗口,代理 ≤640px 长边:用 `--override resize.w/h` 派生,像素段画布随之变小,省时 ~4×)。
- 渲染中:旧帧保留 + 右上"渲染中…"徽标 + 可取消(新请求到达即杀旧进程)。
- 手动:画布工具条 [对比](wipe,按住空格/鼠标按闪现原帧)、[重渲染](强制)、[关闭自动预览]。
- 像素级重型预设(era_1990 等 ntscrs)自动预览可能 >2s:超过 4s 时自动降级为"仅首帧"并提示;代理尺寸可在设置里改(480/640/960)。

## 7. 输出管理与命名

- 命名规则:`{stem}_{preset_id}[_{intensity}x][-N].{ext}`;目标已存在时自动递增 `-1/-2`,**永不静默覆盖**(引擎 tmp+原子 rename 逻辑保留)。
- 完成卡动作:打开所在目录(主)、在文件管理器中显示该文件、复制路径、再来一次(-1 递增)、换一个。
- 会话历史:最近处理(≤8,缩略图+预设名+时间),点击回到该件的参数状态(预设+覆盖快照)。会话内存,不落盘(隐私)。
- Web 版:已有"保存"下载链接 ✓;桌面版:`show_in_folder` 走系统 API(Tauri `opener` 插件)。
