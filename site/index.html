ERA AXIS

拖动年份，引擎编译那个年代的参数。

rewind-core era 1988 --write my88.json —— 年代轴把任意年份编译成一份完整预设：帧率、画幅、介质损伤、编码痕迹，随年份连续变化。

RUN IT

Rust + ffmpeg，本地起服务，浏览器即界面。

构建需要 Rust stable (edition 2024) 与 ffmpeg ≥ 4.4。Web 服务只监听 127.0.0.1；桌面端是一个 214 行的 Tauri 2 壳。

# build & serve the local web UI
$ cd core && cargo build --release
$ ./webui.sh # → http://127.0.0.1:8137/

# one preset, one file
$ rewind-core run --preset presets/dvd2005.json --input in.mp4 --out-dir out/
→ out/in_dvd2005.mp4

# compile any year into a preset
$ rewind-core era 1988 --write my88.json

# two more dubbing generations
$ rewind-core reclip --input out/in_dvd2005.mp4 --times 2

# batch
$ rewind-core batch --preset presets/patina.json --out-dir out/ a.mp4 b.mp4 c.mov

# overrides never touch the preset file
$ rewind-core run --preset presets/cctv2000.json --input in.mp4 --out-dir out/ \
    --override resize.dar=4:3 --override fps.fps=12.5
MEASURED

8 秒 720p 素材，整段实测。
